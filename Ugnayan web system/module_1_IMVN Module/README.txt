UGNAYAN Module 1 - Integrated Management, Verification & Notification Module

IMPORTANT: CSS files were copied as-is and not edited.

How to run in XAMPP:
1. Copy the folder "ugnayan_module1" into htdocs.
2. Open phpMyAdmin.
3. Import database.sql.
4. Visit: http://localhost/ugnayan_module1/login.php

Default Admin Account:
Email: admin@ugnayan.com
Password: admin123

Included features:
- Resident online registration with document upload
- Account status: Pending, Approved, Rejected
- Secure login only after admin approval
- Resident profile update
- Resident activity history
- Notifications / announcements
- Admin resident verification
- Approve/reject application with reason
- Duplicate registration prevention by email
- Centralized resident database with Purok/status filter
- Admin role-based access
- Dashboard counts / reports summary
- Bulk notification to approved residents
- Audit logs
